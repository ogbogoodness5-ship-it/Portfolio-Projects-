## 📊 Project 1: Sales Performance Dashboard (Power BI)

An interactive two-page Power BI dashboard analyzing product sales, customer, and buyer data across multiple linked tables.

- **Page 1 — Overview:** KPI cards and comparison charts (bar, 100% stacked column) for a quick performance snapshot
- **Page 2 — Trends & Distribution:** Line, scatter, and donut charts breaking down sales trends and customer patterns
- Built relationships between product, sales, and customer tables to support accurate cross-table reporting

**Skills demonstrated:** data modeling, DAX/relationships, dashboard design, data visualization

## 🧹 Project 2: Data Cleaning (SQL)

Cleaned a raw, messy dataset in MS SQL Server, with comments documenting the reasoning behind each step.

- Identified and removed duplicate records using window functions (`ROW_NUMBER()`) and CTEs
- Standardized inconsistent text and category values (e.g. merging variant spellings into one consistent category)
- Converted columns to correct data types (e.g. text/integer dates → proper `DATE` type)
- Resolved null and blank values, including filling gaps by joining records on shared fields

**Skills demonstrated:** SQL querying, CTEs, window functions, data standardization, data quality control
